# AI多言語発音マスター！空耳アクセント判定ゲーム (Multilingual Pronunciation Challenge)

AIがあなたの「日本語の空耳発音」を聴き取り、ターゲット言語（英語・フランス語・中国語・イタリア語）の音韻・アクセント特性をどれだけ再現できているかをリアルタイムに採点・判定するインタラクティブWebゲームです。

## 🎮 ゲーム概要とルール

### 1. お題の仕組み
- **お題①（日本語短文）**: 15文字以下の「他言語の単語やフレーズの音に聞こえる空耳風・ユニークな日本語文章」が出題されます。
  - ※お題①にはお題②で選ばれたターゲット言語の単語は一切含まれません。
- **お題②（ターゲット言語）**: 英語 🇺🇸、フランス語 🇫🇷、中国語 🇨🇳、イタリア語 🇮🇹 の4言語からランダム（またはユーザー指定）で選出されます。

### 2. プレイヤーのミッション
選ばれたターゲット言語の**音韻・母音/子音の癖・声調・アクセント・外国語風訛り**を大げさに意識しながら、日本語のお題文章をマイクに向かって音読してください！

### 3. AIによる音韻判定（Gemini 3 Flash）
AI審査員が「言葉の意味」ではなく、**「音声の物理的音韻・アクセント傾向」**のみを聴き取り、以下の基準で判定します：
- ターゲット言語のアクセント再現度スコア (0〜100点)
- 検出された発音傾向（例: *自然な英語風R/L音*, *カタカナ標準語発音*, *フランス語風鼻濁音* など）
- ワンポイント発音指導アドバイス

---

## ✨ 主な機能

1. **リアルタイム音声波形表示 (Web Audio API)**
   - マイク入力に合わせてインタラクティブに反応するビジュアルオーディオイコライザー。
2. **お手本音声再生 (Web Speech API)**
   - ターゲット言語のネイティブTTS（音声合成）による発音イメージの試聴。
3. **Gemini 3 Flash によるマルチモーダル音声解析**
   - 録音された音声データを直接AIに送出し、高度な音韻・アクセント採点を実行。
4. **スコア＆連続成功ストリーク機能**
   - 高得点（70点以上）達成時に紙吹雪演出（Canvas Confetti）とストリーク（連勝）カウント。
5. **挑戦履歴ログ**
   - 直近の挑戦結果・獲得スコア・判定コメントを履歴一覧として表示。

## 🚀 動作環境・セットアップ

### 必要な環境
- **モダンWebブラウザ**: Google Chrome, Microsoft Edge, Apple Safari（最新版推奨）
- **マイクデバイス**: 音声録音許可が必要です。
- **インターネット接続**: Gemini API呼び出しおよびTailwind CSS/FontAwesome CDN読み込み用。

### 起動手順
1. 本リポジトリをダウンロードまたはクローンします。
2. `multilingual-pronunciation-challenge` ディレクトリに移動します。
3. `index.html` をブラウザで開く（またはローカルWebサーバーで実行する）だけでゲームが開始できます。
